# JavaScript Learning Notes

Learning materials from my JavaScript course at TECHIN: theory notes (converted from course slides) and my own practice exercises. Covers JavaScript basics and DOM manipulation.

## Repository structure

### Theory

- **`!!!js-notes/`** – theory notes and examples, organized by topic:
  intro, operators, if/switch, functions, loops, arrays, dates, strings, objects, DOM (2 parts).
  Notes are in Lithuanian and are based on TECHIN course presentations, which I converted from slides to Markdown with the help of Claude Code.

### Practice exercises

Numbered folders follow the order in which topics were covered in the course:

| Topic | Folders |
|---|---|
| Algorithms and math | `1_algorithms`, `2_math` |
| Conditions (`if`, `switch`, ternary) | `3_if`, `4_switch`, `5_ternary` |
| Functions | `6_funkcijos`, `7_svenciu_festivalis_funkcijos` |
| Loops | `8_ciklai (loops)`, `9_KTU_Ciklai` |
| Arrays | `10_arrays`, `reduce_method` |
| Dates and modules | `06 - Date`, `11_dates_modules` |
| Strings | `12_Strings` |
| Objects | `13_Objects` |
| DOM | `14_DOM` |

### Mini projects

- `tipsCalculator` and `dom_tips+calculator` – tips calculator built with JavaScript and DOM manipulation

### Review

- `JS_kartojimas` – JavaScript review
- `pasiruosimas_kd_2026` – exam preparation
- `js-tipu-pavertimas.md` – notes on type conversion in JavaScript
- `masyvu-metodai.md` – notes on array methods

Variables, operators, conditions, functions, loops, arrays and array methods, dates and modules, strings, objects, DOM manipulation.
