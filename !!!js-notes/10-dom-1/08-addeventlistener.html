08 · Įvykių klausymas — addEventListener

Bet kuriam DOM elementui galima parašyti įvykių klausymo metodą. Tai šiuolaikinis būdas dirbti su įvykiais.

<button id="myBtn">Try it</button>

<script>
document.getElementById("myBtn").addEventListener("click", myFunction);

function myFunction() {
  alert("Hello World!");
}
</script>

Įvykis gali būti bet kuris iš sąrašo: w3schools.com/jsref/dom_obj_event.asp

Pabandyk

Sintaksė

elementas.addEventListener("ivykis", funkcija);

// 1. Įvardinta funkcija
btn.addEventListener("click", myFunction);     // ⚠️ BE skliaustų!

// 2. Anoniminė funkcija
btn.addEventListener("click", function () { ... });

// 3. Arrow funkcija (dažniausiai)
btn.addEventListener("click", () => { ... });

⚠️ Funkcija paduodama be skliaustų: myFunction, ne myFunction(). Su skliaustais funkcija būtų iškviesta iš karto, o klausytojui būtų paduotas jos rezultatas.

Keli klausytojai tam pačiam įvykiui

btn.addEventListener("click", pirmas);
btn.addEventListener("click", antras);   // ✅ abu suveiks

// Palyginimui, senasis būdas:
btn.onclick = pirmas;
btn.onclick = antras;                    // ⚠️ antrasis PERRAŠO pirmąjį

Klausytojo nuėmimas

btn.removeEventListener("click", myFunction);
// ⚠️ veikia tik su ĮVARDINTA funkcija — anoniminės nuimti nepavyks

Dažniausi įvykiai

Grupė Įvykiai
Pelėsclick, dblclick, mousemove, mouseover, mouseout
Lietimotouchstart, touchmove
Klaviatūroskeydown, keyup, keypress
Formosfocus, blur, change, input, submit
Windowload, scroll, resize
