02 · HTML elementų radimas

Norint dirbti su HTML elementais, nustatyti ar pakeisti jų parametrus, juos reikia surasti.

1. Pagal id — getElementById

Element
let elem = document.getElementById('elem');
elem.style.background = 'red';

2. Pagal elemento pavadinimą — getElementsByTagName

The DOM is very useful.

This example demonstrates the getElementsByTagName method.

var x = document.getElementById("main");
var y = x.getElementsByTagName("p");
... y[0].innerHTML;

Kadangi elementų gali būti keli, grąžinama elementų kolekcija, ir norėdami rasti konkretų elementą nurodome jo indeksą (kaip masyve).

3. Pagal klasės pavadinimą — getElementsByClassName

The DOM is very useful.

This example demonstrates the getElementsByClassName method.

var x = document.getElementsByClassName("intro");
... x[0].innerHTML;

4. Pagal css selektorių — querySelector / querySelectorAll

  • The
  • test
  • has
  • passed
let elements = document.querySelectorAll('ul > li:last-child');
for (let elem of elements) { alert(elem.innerHTML); } // "test", "passed"

Rezultatai

⚠️ getElementsBy* grąžina gyvą (live) kolekciją: pasikeitus elementų kiekiui HTML'e, rezultatas atsinaujina. querySelectorAll grąžina statišką — jis neatsinaujina.
