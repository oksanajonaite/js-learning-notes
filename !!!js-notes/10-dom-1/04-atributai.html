04 · Elementų atributai

Atributas — tai HTML žymėje rašoma savybė: id, class, href, src, disabled ir kt.

const div = document.createElement('div');   // sukuriam naują div

div.setAttribute('id', 'theDiv');   // jei id yra — pakeis, jei ne — sukurs
div.getAttribute('id');             // grąžina atributo reikšmę: "theDiv"
div.removeAttribute('id');          // pašalina nurodytą atributą

Pridėjimas — setAttribute

<button type="button" id="myBtn">Click Me</button>

var btn = document.getElementById("myBtn");
btn.setAttribute("class", "click-btn");
btn.setAttribute("disabled", "");

Gavimas — getAttribute

<a href="https://www.google.com/" target="_blank" id="myLink">Google</a>

var link = document.getElementById("myLink");
var href = link.getAttribute("href");     // https://www.google.com/
var target = link.getAttribute("target"); // _blank
Google

Keitimas — setAttribute

<a href="#" id="myLink2">Tutorial Republic</a>

var link = document.getElementById("myLink2");
link.setAttribute("href", "https://www.tutorialrepublic.com");
Tutorial Republic

Šalinimas — removeAttribute

var link = document.getElementById("myLink3");
link.removeAttribute("href");   // nuoroda nustoja būti nuoroda
Google

Paveikslėlio keitimas per .src

<img id="myImage" src="smiley.gif">

document.getElementById("myImage").src = "landscape.jpg";

Dabartinės reikšmės

💡 Dažniausiems atributams yra ir trumpesnis būdas — savybė: link.href, img.src, btn.disabled. Veikia abu būdai, bet setAttribute tinka bet kokiam atributui, taip pat ir savo sugalvotam.
