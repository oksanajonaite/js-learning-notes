07 · DOM įvykiai (senasis on... būdas)

JavaScript gali reaguoti į įvairius DOM elementų įvykius ir vykdyti komandas, t.y. atlikti tam tikrus veiksmus.

Įvykiai:

  • Pelės įvykiai (click, dblclick, mousemove, mouseover, mousewheel)
  • Lietimo įvykiai (planšetės, telefonai ir kt.) (touchstart, touchmove)
  • Klaviatūros įvykiai (keypress, keyup)
  • Formos įvykiai (focus, change, submit)
  • Window įvykiai (scroll, resize)

onclick

<button id="myBtn">Try it</button>
<p id="demo"></p>

document.getElementById("myBtn").onclick = displayDate;

function displayDate() {
  document.getElementById("demo").innerHTML = Date();
}

Click "Try it" to execute the displayDate() function.

onload

Objektas navigator saugo informaciją apie naršyklę. Žemiau parašytas kodas patikrina, ar cookies naršyklėje aktyvuoti.

<body onload="checkCookies()">

function checkCookies() {
  var text = "";
  if (navigator.cookieEnabled == true) {
    text = "Cookies are enabled.";
  } else {
    text = "Cookies are not enabled.";
  }
  document.getElementById("demo2").innerHTML = text;
}

onchange

Atkreipk dėmesį, kaip paimama formos tekstinio lauko reikšmė: document.getElementById("fname").value

function myFunction() {
  var x = document.getElementById("fname");
  x.value = x.value.toUpperCase();
}

Enter your name: <input type="text" id="fname" onchange="myFunction()">
Enter your name:

When you leave the input field, a function is triggered which transforms the input text to upper case.

onmouseover, onmouseout

<div onmouseover="mOver(this)" onmouseout="mOut(this)">Mouse Over Me</div>

function mOver(obj) { obj.innerHTML = "Thank You" }
function mOut(obj)  { obj.innerHTML = "Mouse Over Me" }
Mouse Over Me

💡 this čia reiškia patį elementą, ant kurio įvyko įvykis.

onfocus ir onblur

onfocus — kai į formos teksto įvedimo lauką padedama pelė.
onblur — kai formos teksto įvedimo laukas praranda fokusą.

function myFocus(x) { x.style.background = "yellow"; }

Enter your name: <input type="text" onfocus="myFocus(this)">
onfocus:

When the input field gets focus, a function is triggered which changes the background-color.

onblur:

When you leave the input field, a function is triggered which transforms the input text to upper case.
