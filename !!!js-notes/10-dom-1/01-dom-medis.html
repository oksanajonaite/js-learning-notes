01 · DOM medis ir window objektas

DOM – Document Object Model. Tai būdas JavaScript'ui pasiekti HTML elementus: keisti puslapio turinį, keisti stilių, reaguoti į vartotojo veiksmus.

window — root objektas

                    window
      ┌───────────────┼───────────────┐
     DOM             BOM          JavaScript
   document       navigator        Object
                  screen           Array
                  location         Function
                  frames
                  history
                  XMLHttpRequest

HTML virsta medžiu

<!DOCTYPE HTML>
<html>
<head>
  <title>About elk</title>
</head>
<body>
  The truth about elk.
</body>
</html>

HTML elementai, jų tekstai, tarpai ir perėjimai į kitą eilutę (tarp elementų) sudaro DOM medį. Elementai vadinami mazgais (DOM nodes).

Dažniausiai dirbame su:

  • document – pagrindiniu DOM mazgu
  • element nodes – HTML elementais
  • text nodes – tekstas, enter ir tarpai
  • kartais dar su komentarais

Paleisk ir pažiūrėk

💡 Paspausk F12 → Elements, kad pamatytum šio puslapio DOM medį, ir Console, kad pats pabandytum komandas.
