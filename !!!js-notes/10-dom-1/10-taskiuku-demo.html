10 · Viską sudedam kartu: taškiukų demo

Šis pavyzdys sujungia beveik viską iš šios temos: įvykio klausymą, elemento kūrimą, klasės priskyrimą, stiliaus keitimą ir event objekto savybes.

<style>
  body { height: 200px; background: beige; }
  .dot {
    height: 8px; width: 8px;
    border-radius: 4px;   /* rounds corners */
    background: blue;
    position: absolute;
  }
</style>

<script>
  window.addEventListener("click", event => {
    let dot = document.createElement("div");
    dot.className = "dot";
    dot.style.left = (event.pageX - 4) + "px";
    dot.style.top  = (event.pageY - 4) + "px";
    document.body.appendChild(dot);
  });
</script>

Ką daro kiekviena eilutė

💡 event.pageX — pelės X koordinatė nuo puslapio pradžios. Atimame 4, nes taškiukas yra 8px pločio — taip jo vidurys atsiduria ten, kur paspaudei, o ne kairysis viršutinis kampas.

Kitos svarbios koordinatės

Savybė Nuo ko skaičiuojama
event.clientX/Ynuo matomos lango dalies (slenkant puslapį keičiasi)
event.pageX/Ynuo viso puslapio pradžios
event.offsetX/Ynuo paties elemento kampo
