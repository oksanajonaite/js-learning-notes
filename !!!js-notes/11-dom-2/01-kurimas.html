01 · DOM elementų kūrimas

Trys žingsniai

1. Teksto kūrimas:

var node = document.createTextNode("This is new.");

2. HTML elemento kūrimas:

var para = document.createElement("p");

3. Teksto ir elemento sujungimas
(analogiškai vyksta ir dviejų elementų sujungimas, naujas elementas pridedamas tėvinio elemento gale)

para.appendChild(node);
  ↑              ↑
prie kurio     kurį elementą
elemento       jungiame

Pilnas pavyzdys

<div id="div1">
<p id="p1">This is a paragraph.</p>
<p id="p2">This is another paragraph.</p>
</div>

<script>
var para = document.createElement("p");
var node = document.createTextNode("This is new.");
para.appendChild(node);
var element = document.getElementById("div1");
element.appendChild(para);
</script>

This is a paragraph.

This is another paragraph.

‼️ Naujai sukurtas elementas nematomas puslapyje, kol jis nepridedamas prie jau esamo elemento (appendChild).

Ką rodo kiekvienas žingsnis

Trumpesnis būdas: textContent

// vietoj dviejų eilučių:
var node = document.createTextNode("This is new.");
para.appendChild(node);

// galima rašyti vieną:
para.textContent = "This is new.";

💡 createTextNode praverčia, kai tekstą reikia pridėti šalia jau esančio turinio. Jei elementas tuščias — textContent trumpiau ir aiškiau.

Naujesni metodai: append / prepend

element.appendChild(para);     // senasis: TIK vieną elementą, grąžina elementą
element.append(para);          // naujasis: kelis iš karto, galima ir tekstą
element.append(para, "tekstas", kitas);
element.prepend(para);         // į PRADŽIĄ, ne į galą
