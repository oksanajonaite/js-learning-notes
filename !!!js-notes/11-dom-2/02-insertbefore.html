02 · Elemento vietos nurodymas — insertBefore

Įterpiant naują elementą, galima nurodyti jo vietą:

element.insertBefore(para, child);
   ↑            ↑      ↑
Į kurį       Kurį    Prieš kurį
elementą     elementą  elementą
įterpiam     įterpiam  įterpiam

Pavyzdys

<div id="div1">
<p id="p1">This is a paragraph.</p>
<p id="p2">This is another paragraph.</p>
</div>

<script>
var para = document.createElement("p");
var node = document.createTextNode("This is new.");
para.appendChild(node);

var element = document.getElementById("div1");
var child = document.getElementById("p1");
element.insertBefore(para, child);
</script>

This is a paragraph.

This is another paragraph.

Rezultatas

💡 Jei antras argumentas yra null, elementas įdedamas į galą — tada insertBefore(para, null) veikia lygiai kaip appendChild(para).

Naujesni, paprastesni metodai

Juos rašyti patogiau, nes nereikia kreiptis į tėvinį elementą — dirbi tiesiai su kaimynu:

// senasis būdas — reikia TĖVINIO elemento
element.insertBefore(para, child);

// naujasis — dirbi su pačiu elementu
child.before(para);    // prieš child
child.after(para);     // po child
child.replaceWith(para); // vietoje child
