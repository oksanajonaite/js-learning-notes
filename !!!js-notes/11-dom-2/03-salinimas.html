Senesnis būdas: removeChild()

Prieš atsirandant remove(), elementą šalinti galėjo tik jo tėvinis elementas:

var parent = document.getElementById("div1");
var child = document.getElementById("p1");
parent.removeChild(child);

// arba surandant tėvą automatiškai:
child.parentNode.removeChild(child);

💡 remove() yra trumpesnis ir aiškesnis — naujame kode naudok jį. removeChild() verta pažinti, nes jį dar sutiksi senesniame kode, ir jis grąžina pašalintą elementą (todėl jį galima kur nors perkelti).

Visų vaikų išvalymas

// 1. Greičiausia
element.innerHTML = "";

// 2. Po vieną
while (element.firstChild) {
  element.removeChild(element.firstChild);
}

// 3. Su replaceChildren (naujausia)
element.replaceChildren();
