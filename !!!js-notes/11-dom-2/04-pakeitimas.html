04 · DOM elementų pakeitimas

replaceChild()

<div id="div1">
<p id="p1">This is a paragraph.</p>
<p id="p2">This is another paragraph.</p>
</div>

<script>
var parent = document.getElementById("div1");
var child = document.getElementById("p1");
var para = document.createElement("p");
var node = document.createTextNode("This is new.");
para.appendChild(node);
parent.replaceChild(para, child);
</script>
parent.replaceChild(para, child);

Rezultatas

⚠️ Argumentų tvarka lengvai supainiojama: pirma NAUJAS, paskui SENAS. Įsimink taip: „pakeisk šituo — šitą“.

Naujesnis būdas: replaceWith()

Nereikia kreiptis į tėvinį elementą — dirbi tiesiai su tuo, kurį keiti:

// senasis: per TĖVINĮ elementą
parent.replaceChild(para, child);

// naujasis: pats elementas
child.replaceWith(para);
