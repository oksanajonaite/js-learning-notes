05 · Praktinis pavyzdys

Tipinis būdas, kaip JS'u įdedamas turinys į tuščią „konteinerį“.

<!-- your html file: -->
<body>
  <h1>
     THE TITLE OF YOUR WEBPAGE
  </h1>
  <div id="container"></div>
</body>
// your javascript file
const container = document.querySelector('#container');

const content = document.createElement('div');
content.classList.add('content');
content.textContent = 'This is the glorious text-content!';

container.appendChild(content);

Keturi žingsniai

Kodėl taip, o ne innerHTML?

// 1 būdas — innerHTML (trumpiau)
container.innerHTML = '<div class="content">This is the glorious text-content!</div>';

// 2 būdas — createElement (ilgiau, bet saugiau)
const content = document.createElement('div');
content.classList.add('content');
content.textContent = 'This is the glorious text-content!';
container.appendChild(content);

Ciklas: daug elementų iš masyvo

Taip kuriami sąrašai iš duomenų — labai dažnas uždavinys:

const prekes = ["Duona", "Pienas", "Sūris"];
const ul = document.querySelector("#sarasas");

prekes.forEach((preke) => {
  const li = document.createElement("li");
  li.textContent = preke;
  ul.appendChild(li);
});

    ⚠️ Prieš kuriant naują sąrašą dažniausiai reikia išvalyti seną (ul.innerHTML = ""), kitaip elementai kaupsis vienas po kito.
