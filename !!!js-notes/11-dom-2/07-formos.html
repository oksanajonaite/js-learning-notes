07 · Darbas su formomis

preventDefault()

Kad paspaudus submit mygtuką puslapis nepersikrautų, reikia pridėti event.preventDefault() metodą.

form.addEventListener('submit', (event) => {
    // stop form submission
    event.preventDefault();
});

Formos elementų pasiekimas

Galimas su bet kuriuo iš DOM metodų: getElementsByName(), getElementById(), querySelector()

const form = document.getElementById('signup');

arba per formos elements kolekciją:

form.elements[1];         // by index
form.elements['email'];   // by name
form.elements['email'];   // by id

Reikšmių pasiekimas

Formos elementų reikšmės pasiekiamos su savybe value:

const form = document.getElementById('signup');
const name = form.elements['name'];
const email = form.elements['email'];

// getting the element's value
let fullName = name.value;
let emailAddress = email.value;

arba

var age = document.getElementById("age").value;

(užpildyk formą ir paspausk „Registruotis“)

⚠️ value visada grąžina tekstą (string), net ir iš type="number" laukelio. Skaičiavimams reikia Number(...).

Skirtingi laukelių tipai

Tipas Kaip paimti reikšmę
text, email, passwordinput.value → string
numberNumber(input.value) ⚠️
checkboxinput.checked → true/false ⚠️ ne value!
selectselect.value → pasirinkto option reikšmė
radiodocument.querySelector('input[name=x]:checked').value

Tipinė formos tvarkymo schema

const form = document.getElementById('signup');

form.addEventListener('submit', (event) => {
  event.preventDefault();                  // 1. sustabdom persikrovimą

  const vardas = form.elements['name'].value.trim();   // 2. paimam reikšmes

  if (vardas === "") {                     // 3. patikrinam
    alert("Įveskite vardą");
    return;
  }

  console.log("Siunčiam:", vardas);        // 4. darom, ko reikia
});
